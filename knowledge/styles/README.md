# Style bibles

Each folder holds a complete bible for one film style: essence and what it is not, materials and rendering,
colour logic, type, motion quality, camera grammar, sound palette, native moves, pitfalls and a variation space.
Pick one when it serves the subject, blend two, or ignore them and invent. The poster shows the original demo film;
treat it as proof of the look, then make something different (structure, opening, signature shot, camera, score, ending).
