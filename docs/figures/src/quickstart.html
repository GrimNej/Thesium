Quick start
Three steps to your first film.
You need Node.js 22 or newer, FFmpeg and Chrome. thesium doctor checks everything and says how to fix what is missing.
1

Install

In Claude Code
/plugin marketplace add GrimNej/Thesium /plugin install thesium@thesium
Or as a command
$ git clone \ https://github.com/GrimNej/Thesium $ cd Thesium && npm link
2

Ask

Tell Claude what you want
“Make a 20-second launch film for https://example.com, warm and cinematic, in EffectCraft.”
Or in one command
$ thesium make \ "a 20-second launch film for https://example.com"

The model plans, builds, checks and masters it on its own.

3

Watch

In the film's folder
$ node thesium.mjs studio

Play the master, pin notes on the timeline, then press Copy request for the director and paste it back to Claude.

Your film is in out/.
