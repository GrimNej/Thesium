This folder is Drawset's memory of the project. It holds small JSON facts: the parts, the stack, the decisions and the reasons behind them. Agents write them with `drawset note`, and `drawset build` turns them into the page `EXPLAINED.html` at the project root. Commit this folder and the page, so everyone who opens the repository can read it. Git ignores `state/` only, because Drawset rebuilds it.
